## Remaining limitations and readiness

- Source analysis remains heuristic. Cross-file constants, complex control flow, dynamic providers/runtime configuration, overload type inference, generics and chained receivers are not compiler-resolved. Unknown evidence remains unknown; some supported-looking cases are deliberately conservative.
- Inherited method resolution is limited to reliable source/import context; deeper cross-file hierarchies can remain unresolved. Static reachability cannot guarantee runtime call paths or complete reflection/dynamic dispatch coverage.
- Graph vertices can include external/unresolved boundaries; edges aggregate occurrences. The existing JSON field names are retained for compatibility. The PageRank field called percentile is min/max normalization, not an empirical percentile.
- Cycle enumeration is capped/truncated; SCC detection and cycle enumeration are distinct. Path bounds do not make every graph operation traversal-bounded.
- CBOM describes observed source configuration, not negotiated TLS suites, actual keys, providers or exhaustive crypto semantics. TLS without key-establishment evidence is UNKNOWN; migration parameter selection needs separate evidence/review.
- PQC risk is a structural ranking heuristic. Graph failure now produces diagnostics/unavailable status rather than silently claiming complete analysis. Deduplication is per asset for risk and a class union for summary affected counts.
- Ground-truth scope limits benchmark conclusions; recall remains 71.81% for the selected cases. No data was altered to retain old numbers.
- Offline browser interactions passed according to the user’s manual confirmation. Automated browser interaction and console checks were not performed because of the tool access restriction.

The confirmed correctness fixes are regression-verified and ready for code review, with offline dashboard interactions manually confirmed by the user. The documented analysis limitations remain; this is not unconditional release approval. Correctness remediation stops here; no additional feature development or automatic Git publication is included.
